# Contributing

Thank you for reading this first — this repository works a little differently.

**This repository is a release snapshot.** The component is developed in a private monorepo; every release is
published here as **one commit** and one tag. The history you see is the list of releases, not the development
history, and nothing is merged in this repository itself.

**Pull requests are welcome as patches.** A pull request here is reviewed, and if accepted, re-applied in the
monorepo and released with the next tag, with credit in the CHANGELOG. It will not be merged as a commit here,
so please:

- keep it small and focused, with a clear description of the problem it solves;
- sign off every commit (`git commit -s`, the Developer Certificate of Origin, https://developercertificate.org);
- expect it to be closed with a note once it is in a release, not merged.

**Issues** are for bugs and questions about this component. Security reports go through
[SECURITY.md](SECURITY.md), never through public issues.
